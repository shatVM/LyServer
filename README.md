# LyServer — Навчальний простір 📚

> Для роботи нового ШІ-асистента спочатку прочитайте [`AGENTS.md`](AGENTS.md) та [стартовий путівник передачі контексту](docs/AI_HANDOFF.md). Поточний стан завжди звіряйте з GitHub і кодом.

**LyServer («Навчальний простір»)** — це легкий, повністю автономний локальний вебсервер для організації навчання та доступу до матеріалів в умовах відсутності зовнішнього інтернету (наприклад, в укриттях, бомбосховищах або ізольованих навчальних аудиторіях).

Сервер розгортається на одному комп'ютері або ноутбуці та надає доступ до підручників, презентацій і відеоматеріалів усім підключеним пристроям (смартфонам, планшетам, ноутбукам) через локальну мережу або точку доступу Wi-Fi.

---

## 🌟 Основні можливості

- **Повна автономність (Offline-first)**: працює без доступу до Інтернету в замкненій локальній мережі (Wi-Fi роутер або роздача з телефону/ноутбука).
- **Шаблонізатор Handlebars (hbs)**: динамічне відображення сторінок з використанням часткових шаблонів (partials) та розділенням логіки на окремі HBS-компоненти.
- **Модульна архітектура (MVC/Service-based)**: чистий поділ коду на конфігурацію, сервіси, контролери, маршрути та статичні ресурси.
- **Розподіл ролей (Учень / Викладач)**:
  - **Учень**: максимально спрощений та чистий інтерфейс без кнопок керування, завантаження чи паролів. Учень бачить лише дозволені матеріали та великий екран спільної трансляції.
  - **Викладач**: вхід за PIN-кодом, доступ до панелі завантаження, керування трансляцією, а також кнопок приховування та видалення.
- **Приховування та видалення матеріалів (для викладача)**:
  - Кнопка **«Приховати» / «Показати»**: дозволяє приховати матеріал з каталогу учнів, при цьому викладач може в будь-який момент демонструвати цей файл на спільному екрані.
  - Кнопка **«Видалити»**: видалення непотрібних файлів з пам'яті сервера з підтвердженням дії.
- **Спільна синхронізована трансляція**:
  - Викладач транслює матеріал для всієї аудиторії («Показувати всім»).
  - Синхронізація гортання сторінок у PDF-документах.
  - Синхронізація відео/аудіо (відтворення, пауза, перемотування із захистом від розсинхронізації).
- **Особистий перегляд**: кожен учень може відкрити будь-який доступний матеріал локально («Відкрити для себе»), не перериваючи трансляцію для інших.
- **Безпечна робота з кирилицею та ID файлів**:
  - При завантаженні файлів (з українськими або спеціальними назвами) сервер генерує безпечний ідентифікатор файлу (`file_<timestamp>_<random>.<ext>`), а оригінальну кириличну назву зберігає у файлі відповідності `materials/.metadata.json`.
  - У каталозі, списках та плеєрі завжди відображається правильна оригінальна кирилична назва.
- **Посторінкова демонстрація слайдів (PDF та PPTX у PNG)**:
  - Автоматична конвертація документів у чіткі PNG-слайди:
    - **PDF**: рендеринг через `pdfjs-dist` + `canvas` із вбудованими CMap-таблицями та стандартними шрифтами для повного збереження українського тексту та кирилиці без спотворень.
    - **PPTX**: автоматичний експорт кожного слайду презентації PowerPoint у PNG через PowerShell COM-автоматизацію.
  - Демонстрація суворо по одній сторінці (учень бачить лише поточний слайд, наступні слайди не видно).
  - 100% сумісність з мобільними телефонами та старими пристроями (де PDF або PPTX раніше не відкривалися).
- **Потокове передавання великих файлів (до 1 ГБ)**:
  - Підтримка заголовків `Range` (HTTP 206 Partial Content) для швидкого та плавного перемотування медіафайлів.
  - Потокове завантаження файлів (`stream.pipeline`) без перевантаження оперативної пам'яті сервера.
- **Адаптивний інтерфейс**: зручний для використання як на мобільних телефонах, так і на великих моніторах.
- **Конвертація при завантаженні**: PDF/PPTX перетворюються на PNG-слайди одразу після завантаження; учні отримують **лише зображення**, сирі документи їм не віддаються.
- **Перехід за номером слайду**: поле введення номера сторінки (кнопка «Перейти» та Enter) на сторінках демонстрації та особистого перегляду.
- **Перемикання натисканням на зображення**: ліва половина слайда — попередній слайд, права — наступний (біля країв лише стрілки, без тексту). Наведення на комп’ютері або дотик на телефоні підсвічує зону градієнтом; при першому відкритті матеріалу стрілки помітніші, далі — ледь помітні. У самостійному перегляді навігація локальна; на спільній демонстрації слайд перемикає лише викладач.
- **Присутність учнів**: учень заходить з одним полем «Прізвище та ім'я», надсилає «пульс» кожні ~2 с та миттєво повідомляє про неактивність вкладки (Page Visibility API); викладач бачить список онлайн/неактивних (опитування щосекунди) і отримує тост-сповіщення, коли сеанс учня стає неактивним.
- **Захист від перебору PIN**: ліміт спроб, порівняння постійного часу, PIN не друкується в консоль.

## 📁 Підтримувані формати

- **Презентації та слайди**: `.pdf`, `.pptx` (автоматично транслюються у вигляді PNG-слайдів)
- **Відео**: `.mp4`, `.webm`, `.m4v`, `.mov`
- **Аудіо**: `.ogg`, `.mp3`, `.wav`

## 🖥️ Цільове серверне середовище

LyServer розрахований на запуск сервера на **Microsoft Windows** із **Node.js**. Клієнтські пристрої підключаються до нього через локальну мережу.

- Для PDF використовується серверний шлях рендерингу на основі `pdfjs-dist` і `canvas`.
- Для конвертації презентацій PowerPoint `.pptx` у PNG потрібні Windows PowerShell та COM-автоматизація Microsoft PowerPoint. На серверному комп’ютері має бути встановлений Microsoft PowerPoint, а запуск Node.js-процесу має дозволяти доступ до COM-автоматизації.
- **Linux CI не перевіряє реальну конвертацію PowerPoint через COM.** Успішні Linux-тести не замінюють інтеграційної перевірки на Windows із встановленим PowerPoint. PDF fallback і автоматизовані тести перевіряються окремо.
- Після розгортання перевірте конвертацію щонайменше однієї презентації формату `.pptx` на цільовому Windows-комп’ютері.

## 🚀 Швидкий старт

### Вимоги
- Встановлений [Node.js](https://nodejs.org/) (версія 16+ або новіша).

### Запуск сервера

1. Клонуйте або завантажте репозиторій:
   ```bash
   git clone https://github.com/your-username/LyServer.git
   cd LyServer
   ```

2. Встановіть залежності (`express` та `hbs`):
   ```bash
   npm install
   ```

3. Запустіть сервер:
   ```bash
   npm start
   ```
   або:
   ```bash
   node server.js
   ```

   Перевірити роботу коду можна автотестами:
   ```bash
   npm test
   ```

4. Сервер запуститься та виведе адресу в консоль:
   ```text
   Навчальний портал запущено
   На ПК: http://localhost:3000
   У локальній мережі: http://<ВАША_IP_АДРЕСА>:3000
   Каталог матеріалів: ...\LyServer\materials
   PIN викладача: значення за замовчуванням (рекомендовано задати PORTAL_PIN)
   ```

   > Сам PIN-код у консоль не виводиться — задайте його через змінну `PORTAL_PIN`.

## ⚙️ Налаштування (Змінні середовища)

Параметри сервера можна перевизначити через змінні оточення:

| Змінна | За замовчуванням | Опис |
|--------|------------------|------|
| `PORT` | `3000` | Порт, на якому працює вебсервер |
| `PORTAL_PIN` | `2468` | Секретний PIN-код викладача для завантаження файлів та керування трансляцією |
| `PIN_MAX_ATTEMPTS` | `5` | Кількість невдалих спроб PIN до тимчасового блокування |
| `PIN_WINDOW_MS` | `900000` | Вікно часу (мс), за яке враховуються невдалі спроби (15 хв) |
| `PIN_BLOCK_MS` | `900000` | Тривалість блокування (мс) після вичерпання спроб (15 хв) |

**Безпека:** PIN-код порівнюється за постійним часом (`timingSafeEqual`), невдалі спроби
обмежені (після `PIN_MAX_ATTEMPTS` — блокування на `PIN_BLOCK_MS`), власний PIN не друкується
в консоль. Приховані від учнів файли недоступні їм навіть за відомим ідентифікатором.

Приклад запуску з кастомними параметрами:

**Windows (PowerShell):**
```powershell
$env:PORT="8080"; $env:PORTAL_PIN="1357"; node server.js
```

**Linux / macOS:**
```bash
PORT=8080 PORTAL_PIN=1357 node server.js
```

## 📱 Як підключити клас/укриття

1. **Створіть локальну мережу**:
   - Увімкніть Wi-Fi роутер (наявність інтернет-кабелю необов'язкова).
   - Або увімкніть «Мобільний хот-спот» (точку доступу Wi-Fi) на ноутбуці з сервером.
2. **Підключіть пристрої учнів** до цієї ж Wi-Fi мережі.
3. Дізнайтеся локальну IP-адресу комп'ютера з сервером (сервер показує її під час запуску, наприклад `192.168.1.140`).
4. Учні відкривають у браузері на своїх смартфонах/планшетах:
   ```text
   http://192.168.1.140:3000
   ```
5. Викладач вводить **PIN** на панелі керування і завантажує необхідні файли або починає спільну трансляцію.

## 🔌 Опис API

Сервер надає простий REST-подібний HTTP API:

- `GET /` або `GET /materials` — сторінка «Перегляд матеріалів» (каталог та індивідуальний перегляд).
- `GET /upload` — сторінка «Додавання матеріалів» (завантаження файлів з перевіркою PIN).
- `GET /demonstration` — сторінка «Демонстрація» (спільний екран у реальному часі та керування показом).
- `GET /health` — перевірка статусу сервера (`{"status":"ok"}`).
- `GET /api/files` — список доступних файлів у папці `materials/` (для учнів повертає лише видимі файли, для викладача з заголовком `X-Portal-Pin` — усі файли включно з прихованими).
- `GET /api/state` — поточний стан синхронізації (активний файл, сторінка PDF, час відео, статус відтворення, номер ревізії).
- `POST /api/auth/verify` — перевірка PIN-коду викладача (`{ "pin": "..." }`).
- `POST /api/files/toggle-hide` — приховування/показ матеріалу від учнів (`{ "pin": "...", "file": "...", "hidden": true/false }`).
- `POST /api/files/delete` — видалення файлу з сервера (`{ "pin": "...", "file": "..." }`).
- `POST /api/control` — оновлення стану трансляції (перемикання файлу, зміна сторінки, play/pause). Вимагає `{ "pin": "..." }` у JSON-тілі.
- `POST /api/slides/prepare` — примусова конвертація документа у PNG-слайди. Вимагає PIN викладача (заголовок `X-Portal-Pin` або поле `pin`).
- `GET /api/slides/info?file=<name>` — стан слайдів: `{ ready, pageCount }` або `{ converting: true }`.
- `POST /api/presence/heartbeat` — «пульс» учня: `{ studentId, name, active }` кожні ~2 с та при зміні активності вкладки (accepts JSON і form-data для `navigator.sendBeacon`).
- `GET /api/presence/students` — список підключених учнів зі статусом онлайн/неактивний. Тільки для викладача (PIN).
- `POST /api/upload?name=<filename>` — завантаження файлу на сервер (до 1 ГБ). Вимагає заголовок `X-Portal-Pin: <PIN>` та бінарне тіло запиту (`application/octet-stream`).
- `GET /files/<filename>` — потоковий перегляд файлу (підтримує заголовок `Range` для перемотування медіа; доступний учням і під час показу прихованих файлів).

## 📄 Ліцензія

Проєкт розповсюджується для відкритого та вільного освітнього використання.
