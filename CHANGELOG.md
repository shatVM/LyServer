# Журнал змін LyServer

Цей журнал фіксує важливі зміни проєкту та документації. Він не замінює історію Git-комітів і не повинен дублювати кожну дрібну зміну коду.

## 2026-10-21
- Issue #61: навігація слайдами натисканням на ліву/праву половину зображення (принцип галереї). Зони `.slide-zone` охоплюють половини області глядача, містять лише SVG-стрілку без текстових підписів (`aria-label` для скрінрідерів). Ліва — попередній слайд, права — наступний; на першому/останньому слайді перемикання клампиться чинними `stepLocalPage`/`setSharedPage`.
- Градієнти: звичайний стан 15% непрозорості біля краю, активний (наведення/дотик) 50%; ліва й права зони дзеркальні, затемнюється лише активна зона; перехід 220 мс.
- Початкова підказка: при новому відкритті матеріалу обидві стрілки добре помітні (`#viewer.nav-hint`), після першого натискання стають ледь помітними (opacity 0.35); підказка скидається лише при відкритті іншого матеріалу.
- Режими: у самостійному перегляді навігація локальна; на сторінці «Демонстрація» зони створюються лише в викладача (клієнт `slideNavAllowed()` + прибирання зон при зміні ролі), тому натискання учня не змінює спільний слайд. На дотик додається клас `is-active` на 220 мс; `touch-action: manipulation` і захист від зміщення >10 px не блокують прокручування.
- `test.js`: додано 9 автоперевірок Issue #61 (8 функціональних + 1 регресія кольору зон). Разом 40 перевірок.
- Виправлення Issue #61: глобальні стилі `button:hover` (`background: #144985`) і `button:active` (`transform: scale(0.98)`) мають вищу специфікацію за `.slide-zone` — при наведенні/дотику зона заливалася синім замість чорного градієнта. Додано явний скид (`border-radius: 0`, `background: transparent`, `transform: none`, `transition: none` + `.slide-zone:hover/.slide-zone:active`), у зоні лишається лише градієнт з `::before`.
- Швидкість оновлення статусу присутності: опитування викладачем `pollPresence` — щосекунди (`PRESENCE_POLL_MS = 1000`), heartbeat учня — кожні 2 с (`HEARTBEAT_MS = 2000`), тайм-аут офлайну `TIMEOUT_MS` — 6 с; опитування стану демонстрації — кожні 500 мс. Миттєві канали (Page Visibility API + `sendBeacon`) збережено.
- Виправлено: вхід викладача/учня в поточній сесії тепер одразу запускає опитування присутності та heartbeat — раніше списки оновлювалися лише після перезавантаження сторінки.
- `views/demonstration.hbs`: блоки «👥 Учні» та «Запуск показу» поміняно місцями (учні — праворуч від «Спільного екрана», показ — нижче на всю ширину).
- `test.js`: додано 9 автоперевірок Issue #19 (наявність блоку учнів на `/demonstration` і `/materials`, прихованість блоку для учня `teacher-only` + `display:none`, унікальність `id`, порядок блоків, регресія `/students`, CSS `.students-side-block`, JS-рендер через `.js-students-list`, формат даних присутності). Разом 31 перевірка.
