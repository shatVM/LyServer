## Issue #1: Безпека: ліміт спроб PIN та прибирання PIN з консолі

**Labels:** `security`

**Опис:**

1. PIN-код викладача (`2468` за замовчуванням) перевіряється відкритим порівнянням рядків у `/api/auth/verify`, `/api/control`, `/api/upload`, `/api/files/toggle-hide`, `/api/files/delete` — без ліміту спроб. 4-значний PIN брутиться за лічені хвилини з будь-якого пристрою в мережі.
2. `server.js` друкує PIN у консоль при старті — будь-хто, хто бачить екран або лог, отримує доступ викладача.

**Вимоги:**
- [ ] In-memory лімітатор спроб автентифікації (напр. 5 невдалих спроб → блокування на 15 хв, скидання при успіху);
- [ ] Порівняння PIN через `crypto.timingSafeEqual`;
- [ ] Не друкувати PIN у консоль; виводити лише повідомлення про джерело значення (`PORTAL_PIN` задано / використовується значення за замовчуванням);
- [ ] Оновити README (розділ «Налаштування»).

## Issue #2: Безпека: /api/slides/prepare без авторизації (DoS)

**Labels:** `security`, `bug`

**Опис:** `POST /api/slides/prepare` не перевіряє PIN. Будь-хто в мережі може запустити конвертацію PDF/PPTX. PPTX конвертується через PowerPoint COM (PowerShell) — кілька одночасних запитів вичерпують CPU/RAM і породжують кілька екземплярів PowerPoint.

**Вимоги:**
- [ ] `POST /api/slides/prepare` вимагає PIN викладача (заголовок `X-Portal-Pin` або поле `pin`);
- [ ] Учні готують слайди неявно — через `GET /slides/:name/:page` для дозволених (не прихованих) файлів;
- [ ] Лімітатор спроб з Issue #1 поширюється і на цей ендпоінт.

## Issue #3: Безпека: lock конвертації слайдів (гонка паралельних конвертацій)

**Labels:** `bug`

**Опис:** `slideService.ensureSlides()` перевіряє наявність `manifest.json` і запускає конвертацію. Якщо слайди ще не готові, кожен одночасний запит (30 учнів відкрили новий PDF) запускає власну конвертацію в ту саму теку — гонка файлів і для PPTX — множинні екземпляри PowerPoint.

**Вимоги:**
- [ ] In-flight `Map<fileId, Promise>`: другий і подальші запити чекають той самий проміс;
- [ ] Помилка конвертації не «залипає» в картці (видалення з map у `finally`);
- [ ] Повторна конвертація можлива після зміни mtime вихідного файлу.

## Issue #4: Безпека: приховані файли доступні учням за id

**Labels:** `security`

**Опис:** `GET /files/:name` та `GET /slides/:name/:page` не перевіряють ознаку `hidden`. Файл, прихований викладачем від учнів, фактично доступний кожному, хто знає id (`file_<timestamp>_<random>.ext`). Для слайдів прихованого PDF учень може отримати всі PNG через `/slides/...`.

**Вимоги:**
- [ ] `GET /files/:name`: для ролі «учень» приховані файли → 404;
- [ ] `GET /slides/:name/:page`: приховані файли без PIN → 404 (учень не може ні переглянути, ні запустити конвертацію);
- [ ] Викладач із PIN бачить і транслює приховані файли як раніше.

## Issue #7: Список присутності + тост вчителю про неактивного учня

**Labels:** `enhancement`

**Опис:** Викладач має бачити список учнів зі статусом «онлайн/неактивний», а при втраті учнем активності (закрита вкладка, заснувший пристрій, перехід у фон) — отримувати тост-повідомлення.

**Вимоги:**
- [ ] Учень надсилає heartbeat не лише за таймером (~5 с), а й через Page Visibility API: при `visibilitychange` → одразу повідомлення «активний/неактивний» (`navigator.sendBeacon`);
- [ ] На сервері зберігається `lastSeen` та ознака активності сесії;
- [ ] Сторінка «Учні» показує список зі статусами в реальному часі;
- [ ] Клієнт викладача поллить список і показує тост при переході учня в статус «неактивний» (диф між опитуваннями) — тост доступний на всіх сторінках, де є контейнер тостів;
- [ ] Повернення учня в активний стан — також тост/оновлення статусу.

## Issue #8: Конвертація при завантаженні; учні отримують лише PNG

**Labels:** `enhancement`

**Опис:** PDF/PPTX конвертуються в PNG при першому показі. Потрібно конвертувати одразу при завантаженні на сервер, а учням взагалі не віддавати сирі PDF/PPTX — тільки PNG-слайди.

**Вимоги:**
- [ ] Після успішного `POST /api/upload` сервер автоматично запускає конвертацію в фоні (lock з Issue #3);
- [ ] Статус конвертації видно клієнту (`/api/slides/info` → `converting: true` або окремий стан), UI показує «Конвертація…»;
- [ ] `GET /files/:name` для розширень `.pdf`/`.pptx` віддає 403 учням (викладачу з PIN — дозволено);
- [ ] Відео/аудіо залишаються прямими потоками без змін.
